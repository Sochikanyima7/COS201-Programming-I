# COS201-Programming-I
COS 201 Programming I Practical Assignments
## Week 3: Variables, Data Types, Expressions and Input/Output

### Programs

**1. SimpleCalculator.java**
- Accepts two numbers from the user.
- Calculates their sum, difference, product and quotient.
- Handles division by zero.

**2. AverageCalculator.java**
- Accepts a student's name and three scores.
- Calculates the total and average score.

**3. ItemCost.java**
- Accepts an item name, quantity and unit price.
- Calculates the total cost of the item.

### How to Run the Programs

Open a terminal in the week03 folder.

For SimpleCalculator:
javac SimpleCalculator.java
java SimpleCalculator

For AverageCalculator:
javac AverageCalculator.java
java AverageCalculator

For ItemCost:
javac ItemCost.java
java ItemCost

### Testing
Each program should be tested with sample inputs to confirm that it produces the expected results.
